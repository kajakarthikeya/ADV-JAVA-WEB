🔗 Java & MS Access Connections without DSN

Learn how to establish a connection between Java and MS Access database without using DSN (Data Source Name). This method uses UCanAccess driver for direct database connectivity.

1

Add Required Libraries

Right-click on Libraries in the project tree and add the necessary JAR files (like UCanAccess or jdbc-odbc driver) to enable MS Access connectivity.

Adding UCanAccess JAR files to project libraries
📚 Required Libraries:
  • UCanAccess-5.0.1.jar
  • commons-lang3-3.8.1.jar
  • commons-logging-1.2.jar
  • hsqldb-2.5.0.jar
  • jackcess-3.0.1.jar
6

Run the Program

Create and execute the Java program to establish connection with MS Access database.

💻 Java Code:
package Test;
import java.sql.*;
import java.util.*;

public class Test {
    public static void main(String args[]) {
        try {
            // Load UCanAccess JDBC Driver
            Class.forName("net.ucanaccess.jdbc.UcanaccessDriver");
            
            // Establish connection to MS Access database
            Connection con = DriverManager.getConnection(
                "jdbc:ucanaccess://D:\\vrsec.accdb"
            );
            
            // Create statement object
            Statement st = con.createStatement();
            
            // Execute query to fetch data from 'it' table
            ResultSet rs = st.executeQuery("select * from it");
            
            // Process the result set
            while(rs.next()) {
                System.out.println("emp Number is: " + rs.getInt(1));
                System.out.println("emp name is: " + rs.getString(2));
            }
            
            // Close connections
            rs.close();
            st.close();
            con.close();
            
        } catch(Exception e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}

Click the green Run button to compile and execute the program. The output will show whether the connection to MS Access was successful.
