🚀 Introduction to Advanced Java

Core Java vs Advanced Java

☕
Core Java

  • Data types, variables, operators

  • Collections framework
Advanced Java
  • Web development (Servlets, JSP)
  • Database connectivity (JDBC)
  • Enterprise applications (EJB)
  • Frameworks (Spring, Hibernate)
  • Web services and APIs

Java Applets Features

🖥️
Platform Independent: Runs on any browser with JVM
Secure: Runs in sandbox environment with restricted access
Interactive: Provides rich GUI components and event handling
Dynamic: Can be updated without recompiling the entire application
Portable: Write once, run anywhere capability

Java Servlets Key Features

🌐
Server-side Processing: Handles client requests on the server
Protocol Independent: Can handle HTTP, FTP, SMTP protocols
Persistent: Remains in memory until explicitly destroyed
Efficient: Multithreaded architecture for better performance
Robust: Built-in memory management and exception handling

Applets vs Servlets

⚖️
Applets
  • Client-side execution
  • Runs in web browser
  • GUI-based applications
  • Limited security access
  • Requires JVM on client
Servlets
  • Server-side execution
  • Runs on web server
  • Web-based applications
  • Full server access
  • No client-side requirements

JDBC and ODBC Role

🗄️
JDBC (Java Database Connectivity)

Provides a standard API for Java applications to connect and interact with databases. Enables database-independent programming through driver management and SQL execution.

ODBC (Open Database Connectivity)

Microsoft's standard API for accessing database management systems. Provides a common interface for applications to access different database systems.

ODBC vs JDBC

🔄
ODBC
  • Language independent
  • Platform dependent (mainly Windows)
  • Uses C/C++ interface
  • Requires client-side installation
  • Older technology
JDBC
  • Java specific
  • Platform independent
  • Pure Java interface
  • No client-side installation needed
  • Modern, object-oriented

Cookies vs Sessions

🍪
Cookies
  • Stored on client-side
  • Limited storage (4KB)
  • Persistent across sessions
  • Can be disabled by user
  • Less secure
Sessions
  • Stored on server-side
  • Unlimited storage
  • Temporary (session lifetime)
  • Cannot be disabled
  • More secure

Spring Boot vs Traditional Spring

🌱
Traditional Spring
  • Complex XML configuration
  • Manual dependency management
  • Requires external server setup
  • More boilerplate code
  • Longer development time
Spring Boot
  • Auto-configuration
  • Embedded servers
  • Starter dependencies
  • Minimal configuration
  • Rapid development

Standalone vs Web Applications

💻
Standalone Applications
  • Desktop-based applications
  • Direct OS interaction
  • No network dependency
  • Platform-specific installation
  • Rich user interface
Web Applications
  • Browser-based applications
  • Server-client architecture
  • Network dependent
  • Platform independent access
  • HTML/CSS/JS interface

            rs.close();
            st.close();
            con.close();

Insert Data Using CallableStatement

Objective: Insert data into Person table using stored procedure.
🗄️ SQL Setup:
CREATE TABLE Person (
    PersonID INT PRIMARY KEY,
    FirstName VARCHAR(255),
    City VARCHAR(255)
);

DELIMITER $$
CREATE PROCEDURE insert_person(
    IN pid INT,
    IN fname VARCHAR(255),
    IN cityname VARCHAR(255)
)
BEGIN
    INSERT INTO Person (PersonID, FirstName, City)
    VALUES (pid, fname, cityname);
END $$
DELIMITER ;
Creating Person table and stored procedure
💻 Java Code:
package employee;
import java.sql.*;

public class Employee {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/238w1a1275";
        String user = "root";
        String password = "";
        
        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection con = DriverManager.getConnection(url, user, password);
            
            // CallableStatement for stored procedure
            CallableStatement cstmt = con.prepareCall("{call insert_person(?, ?, ?)}");
            cstmt.setInt(1, 1);
            cstmt.setString(2, "John");
            cstmt.setString(3, "New York");
            
            int rowsInserted = cstmt.executeUpdate();
            System.out.println(rowsInserted + " record(s) inserted.");
            
            // Display inserted data
            Statement stmt = con.createStatement();
            ResultSet rs = stmt.executeQuery("SELECT * FROM Person");
            System.out.println("\nPersonID\tFirstName\tCity");
            while (rs.next()) {
                System.out.println(rs.getInt("PersonID") + "\t\t" +
                                   rs.getString("FirstName") + "\t\t" +
                                   rs.getString("City"));
            }
            
            rs.close();
            stmt.close();
            cstmt.close();
            con.close();
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

💻 Java Code:
package employee;
import java.sql.*;
import java.util.Scanner;

public class Employee {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/238w1a1275";
        String user = "root";
        String password = "";
        
        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection con = DriverManager.getConnection(url, user, password);
            
            Scanner sc = new Scanner(System.in);
            System.out.print("Enter salary value X: ");
            double x = sc.nextDouble();
            
            String query = "SELECT empno, ename, salary FROM employee WHERE salary > ?";
            PreparedStatement pstmt = con.prepareStatement(query);
            pstmt.setDouble(1, x);
            
            ResultSet rs2 = pstmt.executeQuery();
            System.out.println("\nSerial\tEmpNo\tName\tSalary");
            int serial = 1;
            while (rs2.next()) {
                System.out.println(serial++ + "\t" +
                                   rs2.getInt("empno") + "\t" +
                                   rs2.getString("ename") + "\t" +
                                   rs2.getDouble("salary"));
            }
            
            rs2.close();
            pstmt.close();
            con.close();
            sc.close();
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

    • " + topping + "

    ");

response.addCookie(ck); // adding cookie in the response

    ⚖️ Cookies vs Sessions Comparison

    🍪
    Cookies
    • Stored on client-side (browser)
    • Limited storage capacity (4KB)
    • Persistent across browser sessions
    • Can be disabled by user
    • Less secure (visible to user)
    • Suitable for user preferences
    🔐
    Sessions
    • Stored on server-side
    • Unlimited storage capacity
    • Temporary (session lifetime)
    • Cannot be disabled by user
    • More secure (server-side)
    • Suitable for sensitive data

    Session Controller

    💻 SessionController.java:
    package com.example.sessiontrackingapp1.controller;

import com.example.sessiontrackingapp1.model.User;
import com.example.sessiontrackingapp1.repository.UserRepository;
import jakarta.servlet.http.HttpSession;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class SessionController {

    @Autowired
    private UserRepository userRepository;

    @GetMapping("/session")
    public String handleSession(@RequestParam(value = "username", required = false) String username,
                                HttpSession session) {

        if (username != null && !username.isEmpty()) {
            session.setAttribute("username", username);

            // Save user to H2 DB
            User user = new User(username, username + "@example.com");
            userRepository.save(user);
        }

        String sessionUsername = (String) session.getAttribute("username");

        if (sessionUsername != null) {
            return "Welcome back, " + sessionUsername + "!";
        } else {
            return "Enter your username in URL parameter: ?username=YourName";
        }
    }
}
    📝 Controller Explanation:
    • Accepts username as a URL parameter (/session?username=John)
    • Stores username in HTTP session
    • Saves user details in H2 database
